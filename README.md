# again-website

Website: https://579lvv.github.io/again-website/

This repository is the independently deployable static website. `preview.html` is used by the resume when present.

The source project and build script are maintained locally in `portfolio.vv`; run `split_pages.py --sites again-website` to rebuild this site. GitHub Pages serves `main` from the repository root. AI backend services are not hosted by Pages.
